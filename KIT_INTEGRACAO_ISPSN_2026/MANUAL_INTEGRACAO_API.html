📘 Manual de Integração e Contrato REST API (v1.0)

Módulo de Cobertura Docente ↔ Sistema de Gestão Escolar (ISPSN)

Ambiente de Produção / Staging:
URL Base: https://docentes.ispsn.app/index.php
Header de Autenticação Obrigatório: Authorization: Bearer ISPSN_INTEGRATION_KEY_2026_SECRET_TOKEN

1. Endpoints Oficiais da API

GET 1. Estado da Conexão & Estatísticas Globais

Endpoint: ?api=v1_integracao_status

GET https://docentes.ispsn.app/index.php?api=v1_integracao_status
Headers:
  Authorization: Bearer ISPSN_INTEGRATION_KEY_2026_SECRET_TOKEN

GET 2. Exportação de Matriz Curricular e Docentes Aprovados

Endpoint: ?api=v1_integracao_plano_export&curso_id={ID}&ano={ANO}

Utilizado pelo Gestão Escolar para recolher a matriz oficial e horários homologados (Ex: Fisioterapia = 8).

GET https://docentes.ispsn.app/index.php?api=v1_integracao_plano_export&curso_id=8&ano=2026/27

POST 3. Sincronização em Lote de Docentes & Documentos do RH (ERP ➔ Portal)

Endpoint: ?api=v1_integracao_sync_docentes

Permite sincronizar o cadastro completo dos docentes e todos os seus anexos documentais (BI, CV, Diplomas, Certificados, INAAREES, Agregação Pedagógica) registrados no RH.

POST https://docentes.ispsn.app/index.php?api=v1_integracao_sync_docentes
Content-Type: application/json
Authorization: Bearer ISPSN_INTEGRATION_KEY_2026_SECRET_TOKEN

2. Tabela de Respostas HTTP

Código Estado Descrição
200 OK Operação concluída com sucesso.
207 Multi-Status Gravação parcial (erros detalhados na propriedade erros).
401 Unauthorized Token ausente ou inválido.
404 Not Found Curso ou recurso não encontrado.
